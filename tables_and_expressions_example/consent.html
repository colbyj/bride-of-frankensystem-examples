Tables and Expressions Example

This is the tables_and_expressions_example project for Bride of Frankensystem. It's a demonstration, not a real research study. Any collected data will be discarded, and any cover story is fictional.

This example demonstrates two BOFS features that work well together — the JSONTable data collection system and inline {{ expression }} substitution in questionnaire JSON — including:

  • A three-round clicker task that records every click as a row in the clicks table (round, click index, time since round start, x, y) via a bulk POST to /table/clicks at the end of each round.
  • A one-row per-round summary written to the scores table via /table/scores.
  • A results questionnaire that uses {{ tables.scores.round_score[1] }} bracket-subscript syntax and {{ tables.clicks.total_clicks }} to render a personalized results page with no Python code.
  • Both scalar and group_by exports defined in tables/scores.json.
