Tables and Expressions Example

This example demonstrates two BOFS features that go together: the JSONTable data collection system (with both single-row and bulk inserts) and the inline {{ expression }} substitution available in questionnaire JSON.

What it does

The task is a three-round clicker. While each round is running, every click is captured as one row in the clicks table (round, click index, time since round start, x, y). At the end of each round the JS posts that round's clicks as a single bulk request to /table/clicks and writes a one-row summary to /table/scores.

After the task, a results questionnaire pulls per-round scores from the scores table using the bracket-subscript syntax (tables.scores.round_score[1]) and the click total from tables.clicks.total_clicks. All of these resolve at render time per participant, with no Python code.

Files of interest

  • tables/scores.json – per-round summary table with both scalar and group_by exports.
  • tables/clicks.json – per-click detail table; bulk-POSTed once per round.
  • questionnaires/results.json – uses {{ ... }} placeholders to render a personalized results page.
  • static/my_task.js – captures clicks and posts to both endpoints.
