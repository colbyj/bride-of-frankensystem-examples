Embedding Media Example

This is the embedding_media_example project for Bride of Frankensystem. It's a demonstration, not a real research study — no data is being collected for any purpose and the cover story is fictional.

The text on this page is placeholder consent text; in a real BOFS project it would be replaced with ethics-approved language describing the actual study, risks, data handling, and the right to withdraw.

This example project demonstrates the different ways media (images and videos) can be embedded into a Bride of Frankensystem study. The image below is served from this project's static/ folder and is referenced from this consent template as <img src="/static/example_image.jpg">.
Continue through the pages to see images embedded inside questionnaire instructions and questions, followed by examples of the audio and video question types.
