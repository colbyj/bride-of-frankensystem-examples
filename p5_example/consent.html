p5.js Example

This is the p5_example project for Bride of Frankensystem. It's a demonstration, not a real research study. Any collected data will be discarded, and any cover story is fictional.

This example demonstrates how to embed a JavaScript task (built with p5.js) inside Bride of Frankensystem, including:

  • A custom database table defined in tables/my_task.json that declares the columns the task will post and how they're exported.
  • The p5 task posting JSON to /table/my_task to record participant data.
  • Two ways of embedding HTML into BOFS: an instructions page (with a built-in continue control) and a simple page (which advances the participant by sending them to /redirect_next_page).

The admin panel is accessible at /admin. The password is example.
