The next page uses an entirely custom HTML template that does not extend either of the BOFS Unity base templates. None of the standard BOFS chrome (header, breadcrumbs, footer) appears, so the page looks and behaves like a standalone Unity WebGL build that happens to be served from inside a BOFS project.

Use this layout when you need full control over the surrounding HTML (e.g., to match an existing visual design or to drop in third-party UI that conflicts with BOFS styling).
