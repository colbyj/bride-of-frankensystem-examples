Learning Phase — Linear Menu

You've been assigned to the Linear Menu condition. Commands in this study are organized in a familiar drop-down menu, and you select one by clicking the menu and then clicking the command you want.

On the next page you'll see a File ▾ button. Each trial:

  1. A prompt at the top of the screen names a command (e.g., "Select Save").
  2. Click File ▾ to open the menu.
  3. Click the prompted command to make your selection.

You'll do 12 practice trials in total. After each one you'll see whether you got it right. Try to remember where each command is in the menu — tomorrow you'll be tested on it.
