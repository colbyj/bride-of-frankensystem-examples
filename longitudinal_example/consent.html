Longitudinal Example

This is the longitudinal_example project for Bride of Frankensystem. It's a demonstration, not a real research study. Any collected data will be discarded, and any cover story is fictional.

This example demonstrates how to run a multi-day study in Bride of Frankensystem, including:

  • Two BOFS projects (day1.toml and day2.toml), each with its own page list, database, and port.
  • An external Participant ID collected on day 1 and re-entered on day 2 to link a participant's responses across sessions.
  • CONDITIONS_FROM_DB on day 2, which looks up each returning participant's day-1 condition and re-uses it.
  • An optional CONDITIONS_FROM_CSV alternative for pre-deciding assignments outside the database.
  • conditional_routing on both days so each participant only sees their condition's instructions, task, and recall pages.
