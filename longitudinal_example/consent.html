Menu Learning Study

This is the longitudinal_example project for Bride of Frankensystem. It's a demonstration, not a real research study — no data is being collected for any purpose and the cover story is fictional.

The text on this page is placeholder consent text; in a real BOFS project it would be replaced with ethics-approved language describing the actual study, risks, data handling, and the right to withdraw.

This is a two-day study about how people learn and remember commands in software interfaces. Today you'll spend a few minutes practising a small set of commands using one of two menu styles. Tomorrow you'll come back and test how many of them you can recall.

You'll need to enter the same Participant ID on both days so we can link your responses across sessions.
