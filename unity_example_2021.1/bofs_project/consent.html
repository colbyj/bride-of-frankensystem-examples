Unity WebGL Example Project

This is the unity_example project for Bride of Frankensystem, built with Unity 2021.1. It's a demonstration, not a real research study — no data is being collected for any purpose and the cover story is fictional.

The text on this page is placeholder consent text; in a real BOFS project it would be replaced with ethics-approved language describing the actual study, risks, data handling, and the right to withdraw.

This example demonstrates how to integrate a Unity WebGL build with BOFS, including:

  • Three embedding patterns: inside BOFS's standard page chrome, filling the viewport, and on a fully custom HTML page.
  • Sending the participant ID from BOFS into the running Unity build.
  • Reading the participant's assigned condition from inside Unity via a Flask route.
  • Posting data from Unity back to a custom database table.
  • Advancing the BOFS page flow from within Unity (via a JavaScript plugin).
