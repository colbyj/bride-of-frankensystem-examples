Advanced BOF Project Example

This is the advanced_example project for Bride of Frankensystem. It's a demonstration, not a real research study — no data is being collected for any purpose and the cover story is fictional.

The text on this page is placeholder consent text; in a real BOFS project it would be replaced with ethics-approved language describing the actual study, risks, data handling, and the right to withdraw.

This example demonstrates additional capabilities of Bride of Frankensystem, including:

  • Basic and more advanced questionnaires.
  • A questionnaire that includes calculations to score participant responses on export.
  • A questionnaire with a custom question type.
  • Automatic assignment to conditions, with different questionnaire orders per condition.
  • Custom database tables with custom export calculations.
  • Instructions pages.
  • Custom HTML pages that record data to the database.
  • Custom admin pages.

Replace this text with your own consent text before running a real study.
