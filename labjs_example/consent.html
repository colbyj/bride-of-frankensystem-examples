lab.js + BOFS Example

This is the labjs_example project for Bride of Frankensystem. It's a demonstration, not a real research study. Any collected data will be discarded, and any cover story is fictional.

This example demonstrates how to integrate lab.js as the in-browser experiment runner with Bride of Frankensystem providing the surrounding infrastructure, including:

  • BOFS handling consent, demographics, instructions, a post-task questionnaire, and overall page flow.
  • lab.js running a short Stroop task (about 24 trials) inside a BOFS custom/ page so it takes the full viewport with no BOFS chrome.
  • Trial data POSTed back from lab.js into a BOFS-managed custom database table (labjs_trials) that's exportable through the admin panel.

The admin panel is accessible at /admin. The password is example.
