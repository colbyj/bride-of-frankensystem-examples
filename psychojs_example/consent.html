PsychoJS + BOFS Example

This is the psychojs_example project for Bride of Frankensystem. It's a demonstration, not a real research study. Any collected data will be discarded, and any cover story is fictional.

This example demonstrates how to integrate PsychoJS as the in-browser experiment runner with Bride of Frankensystem providing the surrounding infrastructure, including:

  • BOFS handling consent, demographics, instructions, a post-task questionnaire, and overall page flow.
  • A Stroop task originally built in PsychoPy Builder and exported to PsychoJS, with the generated quitPsychoJS function adapted to send trial data to BOFS instead of Pavlovia.
  • The PsychoJS task running inside a BOFS custom/ page so it takes the full viewport with no BOFS chrome.
  • Trial data POSTed back from PsychoJS into a BOFS-managed custom database table (psychojs_trials) that's exportable through the admin panel.

The admin panel is accessible at /admin. The password is example.
