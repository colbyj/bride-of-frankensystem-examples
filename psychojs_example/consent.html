PsychoJS + BOFS Example

This is the psychojs_example project for Bride of Frankensystem. It's a demonstration of integrating PsychoJS as the in-browser experiment runner while BOFS handles consent, questionnaires, condition assignment, page flow, and data storage. The PsychoJS side is a Stroop task originally built in PsychoPy Builder and exported, with the generated quitPsychoJS function adapted to send trial data to BOFS instead of Pavlovia. No data is being collected for any purpose and the cover story is fictional.

The text on this page is placeholder consent text; in a real BOFS project it would be replaced with ethics-approved language describing the actual study, risks, data handling, and the right to withdraw.

You will be asked some demographic questions, complete a short Stroop task (about 45 trials, ~3 minutes), and then answer a brief follow-up.
